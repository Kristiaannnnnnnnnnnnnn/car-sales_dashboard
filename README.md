# Car Sales Performance Dashboard

## Project Overview

This project features an interactive **Car Sales Dashboard** developed using Microsoft Power BI to monitor and evaluate sales performance, revenue, pricing patterns, and vehicle sales across various categories and dealership regions.

The dashboard converts raw car sales data into meaningful visual insights, helping users identify trends, assess business performance, and make informed, data-driven decisions.

## Key Performance Indicators (KPIs)

The dashboard highlights the following performance metrics:

- **YTD Total Sales:** $75.20M
- **YTD Cars Sold:** 1,312 units
- **YTD Average Selling Price:** $57.32K
- **Year-over-Year Sales Growth:** -26.2%

## Dashboard Features

The dashboard includes several interactive visualizations and analytical components:

- 12 KPI cards displaying key sales figures, average prices, and vehicle quantities.
- Weekly sales trend analysis to monitor changes in sales performance.
- Sales breakdown by vehicle body style and color.
- Geographical visualization of sales performance across dealer regions.
- Company-level sales performance presented in a detailed table.
- Interactive slicers for filtering data by body style, dealer name, transmission type, and engine specifications.
- Detailed records of individual car sales for more in-depth analysis.

## Tools and Technologies

The project was developed using the following tools and technologies:

- Microsoft Power BI Desktop
- Power Query for data transformation and cleaning
- DAX (Data Analysis Expressions) for calculations and measures
- Data Modeling
- Data Visualization

## Dashboard Pages

**Page 1 – Sales Overview**

Provides a comprehensive summary of car sales performance through KPI indicators, sales trend charts, category-based visualizations, and regional dealership analysis.

**Page 2 – Sales Details**

Presents detailed car sales information, allowing users to explore individual records and customize their analysis using interactive filters.

## Project File

**File Name:** `Car_Sales_Dashboard_Final.pbix`

The Power BI file can be downloaded and opened in Microsoft Power BI Desktop to explore the dashboard's interactive features and visual reports.

## Project Objective

This project was created as a hands-on data analytics initiative to showcase practical skills in data preparation, data transformation, data modeling, DAX calculations, and interactive dashboard development using Power BI.
